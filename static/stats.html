How these numbers are counted

  • People means distinct visitors that day. Two visits from the same person on the same day count once.
  • Nobody is identified. The site stores a scrambled code for each visitor, made from their network address plus a secret that changes every day. The code cannot be reversed, and Monday's code cannot be matched to Tuesday's.
  • No cookies, no accounts, no names.
  • Counts reset when the free server restarts. That is a limitation of the free hosting, not a trick.
