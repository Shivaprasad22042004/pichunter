Why "non-commercial" matters InsightFace releases the code freely, but the trained weights come from research datasets that are restricted. Using them for a free tool like this one is within those terms. Selling a service built on them is not. Contact recognition-oss-pack@insightface.ai if you need a commercial licence.

How the models were made smaller

The original models were 191 MB, which is too heavy for a free server. They were reduced to 48 MB by storing their internal weights at lower precision (int8 instead of float32). ONNX Runtime's quantisation tools do this automatically.

The face index was compressed the same way: 82,620 faces × 512 numbers went from 169 MB to 42 MB. The results were checked against the uncompressed version first — every match was identical. Several more aggressive compression schemes were tried and rejected because they silently lost real matches.
