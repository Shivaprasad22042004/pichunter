🔒 Privacy — what happens to your photo

You are about to upload your face to a website run by a classmate. That deserves a straight answer about what happens to it.

The short version

Your photo is used for one thing, for a few seconds, and then thrown away. It is not saved. It is not shown to anyone. It is not sent anywhere else.

Exactly what happens, in order

1You choose a photo on your deviceon your device only
2It is sent to the server over an encrypted (HTTPS) connectionin transit
3The server finds your face and turns it into 512 numbersin memory
4The server compares those numbers with the archivein memory

6You get a list of file names—

What is definitely not done

  • Your photo is not written to disk anywhere — not by this site.
  • Your photo is not stored in a database.
  • Your photo is not shown to anyone, including other users.
  • Your photo is not sent to any third party. The face comparison runs on the same server.
  • There are no advertising trackers and no analytics scripts.
  • You do not need an account, and you are never asked for a name or email.

What is recorded, and why

So that the site can report how many people used it, a counter is updated each time someone searches. Only three things are kept:

  • the day (for example 2026-11-10) — not the time and not a sequence of events
  • a scrambled version of the visitor's network address, used only to count each person once per day
  • whether that visitor's search found any photos

No per-visit log is kept. The numbers are totals per day, not a list of who did what and when. The site cannot reconstruct a visitor's activity, because nothing records it in the first place.

How the scrambling works

The address is never stored, in whole or in part. It is passed through a one-way fingerprint function together with a secret, which produces a short code like 0cd52df063a71543. That code is stored instead of the address.

The secret is combined with the date and changes every day, so the same person on Monday and Tuesday produces two codes that look completely unrelated. Nobody can tell they are the same person.

One honest limit: the fingerprint is not random — it is keyed. Anyone who knew the secret could test a guessed address against a stored code and confirm a match. The secret is not published and is stored only as a server setting, so this is not something a visitor or a stranger can do — but it is the correct description, rather than claiming the address is mathematically unrecoverable by anyone.

The numbers are public at Stats. They contain no names, no addresses and no individual records.

About the archive photos

The graduation photos themselves are not stored on this website. The site only knows which face belongs to which file name. That was a deliberate choice: those photos contain thousands of people who did not choose to be published.
